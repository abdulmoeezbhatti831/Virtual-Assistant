# Virtual Assistant (Jarvis / Friday)

Author: Abdul Moeez Bhatti

- This is a customizable voice-powered Virtual Assistant built in Python that helps automate daily tasks with simple voice commands. It can open apps like Google, YouTube, Camera, perform Google/Wikipedia searches, play music, send WhatsApp messages & emails, control files/folders, and even run commands in the terminal.

- The assistant is fully interactive with speech recognition and text-to-speech responses, making the experience feel conversational. It also comes with a fun loading animation, chatbot like chatting integration using OpenAI API KEY taking from user, and exciting programs to explore.

- Whether you want to boost productivity, automate repetitive actions, or just have some fun with your own AI assistant, this project is designed to be both useful and enjoyable.
